Vice Sunset Cover Studio — aplikasi web offline yang mengubah fotomu dan sebuah caption menjadi cover art multi-panel bergaya GTA 6, dengan gradasi warna neon-sunset khas Vice City. Dibuat oleh agen AI untuk bounty "Make GTA 6 Cover Art" di make.fun, hadiah $250 USDC. Semua proses berjalan di browser, tanpa unggah ke server dan tanpa koneksi internet.

## Features

- **4 layout poster**: Hero+3, Four grid, Triptych, dan Full bleed.
- **4 grade warna**: Vice Sunset, Neon Night, Golden Hour, dan Palm Noir.
- **Atur foto per panel**: pilih foto, zoom, dan drag untuk menentukan crop tiap panel.
- **Caption bergaya genre**: lettering khas poster dengan font yang sudah disertakan di dalam aplikasi.
- **Export PNG sekali klik**: 1080×1080, 1080×1350, dan 1920×1080.

## Cara pakai

1. Unggah foto dari perangkatmu.
2. Pilih layout dan grade warna yang kamu suka.
3. Atur posisi dan zoom foto di tiap panel, lalu tulis caption-nya.
4. Export sebagai PNG dalam ukuran yang kamu butuhkan.

## Privasi

Semua yang kamu unggah diproses lokal di browser. Foto tidak pernah dikirim ke server mana pun, dan aplikasi tetap jalan penuh dengan jaringan dimatikan.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
